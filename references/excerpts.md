# 摘录模式

摘录服务于理解与日后检索，不追求覆盖全文。

## 选择标准

优先保留：

- 作者的核心命题或结论
- 关键定义与概念边界
- 推理链中的转折、因果机制或证据
- 极具表达价值且难以无损转述的句子
- 与用户问题直接相关、未来可复用的段落

排除重复表述、脱离语境易误导的金句、只起过渡作用的文字。默认 5–8 条；长段只截取必要连续部分，并说明省略不改变原意。

## 每条摘录

```text
quote: 逐字原文
locator: 页码/章节/段落/时间戳/URL 锚点
source_id: 来源标识
why: 一句话说明价值
context: 仅在脱离上下文会误解时补充
tags: 1–3 个可检索标签
```

## 证据纪律

- 保留原语言、标点和重要强调；更正明显 OCR 错误时显式标注。
- 无法核对原文时不要使用引号，改写为“转述”。
- 电子书位置会漂移时优先记录章节 + 段首短语；PDF 优先页码。
- 同一摘录不要同时复制到摘要和结论；用引用编号回指。
- 若用户要求摘录比例可能触及版权限制，减少逐字内容并提供定位与转述。

## 输出形态

- 阅读高亮：按来源顺序排列。
- 论证证据：按主张分组。
- 主题摘录：按稳定主题分组，但保留原始定位。
- 笔记输入：每条摘录只绑定一个主要笔记，必要时通过链接复用。
